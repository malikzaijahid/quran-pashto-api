# Contributing to Pashto Quran API

First of all, thank you for considering contributing! 🙏

This project exists to make the Holy Quran accessible to the Pashto-speaking community. Every contribution — big or small — is valued.

---

## 🌟 Ways to Contribute

### 1. Report Bugs

If you find a bug (e.g., incorrect verse, missing surah), please:

1. Check if it's already reported in [Issues](https://github.com/malikzaijahid/quran-pashto-api/issues)
2. If not, [open a new issue](https://github.com/malikzaijahid/quran-pashto-api/issues/new) with:
   - A clear title
   - Description of the bug
   - Surah and verse number (if applicable)
   - Expected vs. actual behavior
   - Screenshots (if helpful)

### 2. Suggest Features

Have an idea? [Open a feature request](https://github.com/malikzaijahid/quran-pashto-api/issues/new) with:

- Clear description of the feature
- Use case
- Why it would be valuable

### 3. Improve Documentation

Documentation improvements are always welcome:

- Fix typos
- Clarify confusing sections
- Add examples
- Translate documentation

### 4. Fix Translation Errors

If you spot a translation error:

1. Verify it with multiple sources
2. Open an issue with the correction
3. Include references

### 5. Add New Features

Want to add a feature?

1. First, open an issue to discuss it
2. Wait for approval
3. Fork and create a branch
4. Make your changes
5. Submit a pull request

## 🚀 Development Setup

### Prerequisites

- Python 3.8+
- Git

```bash

git clone https://github.com/malikzaijahid/quran-pashto-api.git
cd quran-pashto-api

# Optional: Create a virtual environment
